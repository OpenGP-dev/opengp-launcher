OpenGP Launcher @VERSION@ for Windows (x64, Windows 10 or later)

The launcher for OpenGP, the native port of Mario Kart Arcade GP 2 and GP 1:
play either game, add your disc image, install the games, and change their
settings, controls and saves in one window.

Install
1. Unpack OpenGP (OpenGP-<version>-windows-x64.zip) anywhere you can write
   to, such as your Documents folder (not Program Files).
2. Copy everything in this archive's folder into that OpenGP folder, next to
   its sdk folder. Its OpenGP.exe replaces the installer's: the launcher
   installs the games itself.
3. Open OpenGP.exe. Add your disc image, install, play.

Windows may warn that OpenGP.exe is from an unknown publisher (it isn't
signed): choose More info, then Run anyway.
